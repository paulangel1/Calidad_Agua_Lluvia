Nombre del conjunto de datos: Data Histórica de Calidad de Agua Lluvia.
Tema: Calidad y monitoreo de agua lluvia.
Población estudiada: Muestras y mediciones de calidad de agua lluvia recolectadas en diferentes puntos de monitoreo de Colombia.
Entidad que publica los datos: Instituto de Hidrología, Meteorología y Estudios Ambientales (IDEAM).
URL del conjunto de datos: https://www.datos.gov.co/d/iej7-tm45
Cantidad de registros: 25.377 registros.
